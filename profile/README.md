# Cuadrata

The Cuadrata project was created to maintain a small desktop suite written in C,
on CGTK, the Classic GUI Toolkit, a deeply modernized fork of GTK+ 1.2 which runs on
Wayland and X11. The name "Cuadrata" comes from the Latin word "quadrata" which means
"squares", with an emphasis on the C to denote the preferred programming language.

This project aims to build and maintain software that is small, predictable,
understandable, and robust. Many of the programs are ones that people still loved and
wished to continue using, but were discontinued by the organizations behind them.
They are brought back here, built against a toolkit that is capable but still simple
and tiny compared to the toolkits of today. This is the GTK+ 1.2 ecosystem's alternate
history.

One of the major goals is a set of plain, dependable tools for Wayland desktops,
as xterm, xcalc and the other x* programs were for X. With that being said, they
are also great tools to use on X11 desktops.
